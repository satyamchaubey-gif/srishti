# A Little Place For You ♡

A custom Cutiepage-inspired digital gift website using the two photos supplied in the chat.

## Files
- index.html
- style.css
- script.js
- assets/memory-01.jpg
- assets/memory-02.jpg

## Customize
Open `index.html` and edit:
- The heading/name
- The story paragraphs
- The four "tiny things"
- The letter text
- The final message

Replace the two images inside `assets/` if you want to add different memories.

## Run locally
Just open `index.html` in a browser.

## Deploy
Upload the folder to a GitHub repository and enable GitHub Pages, or import the folder into Vercel as a static site.
